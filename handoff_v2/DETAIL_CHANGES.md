`design_handoff_redesign/README.md`의 레버 1~2(토큰·공통 CSS)는 그대로 유효하고, 이 문서는 그 위에 얹는 **차분(diff)** 입니다.

> **VS Code의 Claude에게**: JS 로직·함수 시그니처·onclick·id는 절대 바꾸지 않습니다. 아래 항목은 전부 마크업/CSS 수준의 수정입니다.

## 1. 로그인/랜딩 — `로그인 v2.dc.html`

**가장 큰 수정: 이전 시안의 아이디/비밀번호 + 카카오 로그인은 실제 앱에 없는 기능이라 삭제.**
실제 플로우(역할 선택 → 선생님 비밀번호 / 학부모 이름+PIN / 학생 PIN 키패드)로 다시 그림.

- 좌측 브랜드 패널(#0E2230) + 우측 인증 카드 구조는 유지. `index.html`의 `#s-land`가 이 골격으로 바뀌고, `#s-login`/`#s-pin`/`#s-stupin`은 우측 패널의 상태 전환으로 흡수 가능 (또는 각 화면에 우측 카드 스타일만 적용).
- 역할 카드: 선택 상태 = 틸 테두리 1.5px + `#E3F5FA` 배경 + 아이콘 틸 필. 이모지(🧑‍🏫🎓👨‍👩‍👧) → Lucide(`pencil-line`/`graduation-cap`/`users`).
- 학생 키패드: 키 높이 52px(44px+ 타깃), `active` 시 틸 반전. PIN 점 14px.
- 동명이인 선택(`#stupin-name-sel`)·에러 상태 시안 포함. 에러 필드는 앰버 테두리 + `circle-alert` 아이콘.
- CTA 문구는 역할을 반영: "선생님으로 로그인" / "조회하기" / (학생은 4자리 입력 시 자동 진입).

## 2. 선생님 대시보드 — `선생님 대시보드 v2.dc.html`

- **사이드바를 실제 탭 구성으로 수정**: 대시보드·클래스·학생·과제·테스트·자료 DB·워크시트(+하단 설정). 이전 시안의 '수업 기록' 탭 삭제, '워크시트'(`file-text`) 추가.
- **탑바를 실제 구성으로 수정**: 검색창·알림벨(미구현 기능) 삭제 → 로고 / 아바타+이름 / 로그아웃 버튼.
- 인사말 👋 제거 (G4).
- 통계 카드 4개: 보조행을 `height:20px` 고정 행으로 통일 — 진행바 카드와 텍스트 카드의 세로 리듬이 같아짐.
- '지금' 수업 행: 배경 `#F4FBFC` + `inset 3px 0 0 #0CA4C9` 좌측 스트로크로 강조 (border-left 대신 inset shadow → 레이아웃 밀림 없음).
- 상태 배지·기록 버튼 폭 84px 고정 (G6).
- 달력: 요일 헤더에서 mono 제거(G2), 일요일 `#E05B4F`, 오늘 셀에 틸 그림자, 이전/다음 달 버튼 26px 터치 영역+hover, 범례 스와치에 1px 테두리.
- '전체 보기' 링크에 `chevron-right` 부착.

## 3. 학생 홈 (모바일) — `학생 모바일 v2.dc.html`

- **하단 탭을 실제 5개로 수정**: 오늘·단어·복습·클래스5·오토보카. 이전 시안의 '원서·더보기' 탭 삭제. 외부 링크(클래스5·오토보카)엔 `arrow-up-right` 9px 이탈 표시.
- 탭 타깃 `min-height:52px` (44px+).
- 헤더: 스트릭 배지 + 이름 이니셜 아바타(나가기는 아바타 시트 안으로). 
- 미션 카드: `min-height:56px`, 체크 원 32px.
  - 완료: 배경도 옅은 그린 `#F7FDFA`, 중복이던 ✅ 이모지 제거(체크 아이콘과 중복).
  - 진행 중: 원 안의 알 수 없는 숫자("12") 제거 → `play` 아이콘, 제목 우측에 mono `12/20` 진도 병기.
  - 미시작 토·일: 회색 아이콘 원 대신 8px 점(시각 소음 감소).
- 단어 카드 CTA 버튼 높이 50px.
- 스트릭 카드: 제목의 🔥를 우측 "🔥 5일째" 카운터로 이동(헤더 배지와 호응). 요일 라벨 mono 제거(G2).
- 홈 인디케이터 추가(학부모 시안과 통일).

## 4. 학부모 홈 (모바일) — `학부모 모바일 v2.dc.html`

- 헤더: 알림벨(미구현) → **나가기** 버튼 (실제 앱과 일치).
- 카드 좌측 3px 틸 보더 삭제 — 모든 카드가 같은 색 보더면 의미가 없고 소음. 대신 수업 유형 칩(헤더)·평가 칩(푸터) 분리 유지.
- 평가 칩: 강점(그린, `trending-up`) 항상 먼저 → 중립(슬레이트) → 보완(앰버, `triangle-alert`). 이모지(🎉📖) → Lucide.
- 스티키 탭: 높이 38px 고정 + 스크롤 경계선(`box-shadow:0 1px 0`), 비활성 hover 시 틸 테두리.
- 히어로 요약: 요약 문장을 15px/700으로 승격(핵심 메시지), 숫자에 단위(회·점·권) 병기.
- 월 경계 구분선("5월") 패턴 추가 — 긴 목록 스캔 보조.
- 이번 달 → 지난 달 카드 사이 라벨 구분.

## 5. 적용 순서 제안

1. G1~G6 공통 항목을 `css/style.css`에 반영 (30분).
2. `index.html` 진입/로그인 3화면 → 로그인 v2 골격 (`#s-land` 개편).
3. `js/teacher.js` 대시보드 render → 대시보드 v2 (사이드바는 `index.html`).
4. `js/student.js` 홈 render + `index.html` `.stu-bottomnav`.
5. `js/parent.js` 수업 탭 render + 헤더.

각 단계 후 선생님 로그인 / 학부모 PIN / 학생 PIN 진입이 깨지지 않는지 확인 후 커밋.
