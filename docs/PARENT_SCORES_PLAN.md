## 2. 블록 구성 (제안)

점수 탭을 네 블록으로 나눕니다. **기록이 없는 블록은 아예 숨깁니다** — 빈 카드를 늘리지 않습니다.

```
① 자체 시험      (지금 그대로 · 맨 위)
   · 최근 단어 테스트 점수 + 영역별 막대 + 다시 볼 단어
   · 추이 그래프, 영역별 성장 — 지금 것 유지

② 학교 내신      기록이 있을 때만
   · 학기별 한 줄: 2026-1학기 중간 · 성취도 A · 92%
   · 성취도(A~E)를 크게, 점수는 보조
   · 학교·학년이 다르면 비교하지 않는다 (다른 시험이므로)

③ 모의고사       기록이 있을 때만
   · 회차별 한 줄: 2026-09 · 2등급
   · 등급은 '낮을수록 좋다'를 한 줄로 설명 (1등급이 가장 높아요)
   · 추이는 선 그래프 대신 칩 나열 — 2~3회밖에 없어 선이 과장돼 보인다

④ NELT          기록이 있을 때만
   · 상반기/하반기 한 줄: 2026 하반기 · 78점 · Level 5
   · 점수와 레벨을 같이 (레벨만으로는 학부모가 가늠하기 어렵다)
   · 상반기→하반기 변화가 있으면 ▲/▼ 로
```

**블록 순서의 근거**: 학부모가 매주 보는 것은 ①이고, ②③④는 학기에 한두 번 바뀝니다.
자주 바뀌는 것을 위에 둡니다.

## 3. 지켜야 할 규칙

1. **단어 평균·점수 추이는 자체 시험만** — 내신·모의고사를 섞으면 과목이 다른 점수를 한 선에 잇습니다.
   지금 `parent.js:15`(월간 리포트 쪽)는 `inhouse` 로 걸러져 있지만
   **`parent.js:184`(점수 탭 쪽)는 걸러지지 않습니다.** 구현 때 같이 고쳐야 합니다
   — 내신 시험에 단어 문항이 있으면 그것이 "최근 단어 테스트"로 올라옵니다.
2. **숫자는 코드가 계산하고 AI 문장에 넣지 않습니다.** AI 는 코멘트만 씁니다
   (11/06 에 고친 규칙과 같습니다 — 점수를 AI 가 옮겨 적으면 틀립니다).
3. **'불합격' 같은 말을 쓰지 않습니다.** ②는 성취도를 그대로, ③은 등급을 그대로,
   ④는 점수·레벨을 그대로 — 학원이 매긴 판정을 덧붙이지 않습니다.
4. **기록 없는 블록은 숨깁니다.** 그리고 네 블록이 모두 비었을 때만
   "아직 테스트 기록이 없어요" 를 띄웁니다.
5. 색은 토큰만 (`DESIGN_RULES.md`). 학부모 화면은 Lucide 아이콘입니다.
